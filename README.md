# Proyecto_SMEB_Final
 SMEB (Sistema de Mantenimiento de Equipos Biomédicos) es una aplicación web desarrollada con Next.js y NestJS para optimizar la gestión técnica y documental de equipos biomédicos. Centraliza mantenimientos, inventarios y reportes, mejorando la eficiencia, trazabilidad y control en instituciones de salud. Además se hace monitorización de ubicación de equipos..
